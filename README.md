# X2MD 知识库采集（Chrome 插件）

在 X（Twitter）原生「…」菜单顶部注入「保存到知识库」，点击即把该推文链接提交到你的服务器，云端自动归档为 Markdown + 图片并更新索引。

## 安装

1. Chrome 打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹（`x2md-saver`）

## 配置

点插件图标，填两项：

| 项 | 说明 | 示例 |
|---|---|---|
| 服务器地址 | 部署好的队列服务 | `http://123.45.67.89:8765` 或 `https://kb.example.com` |
| 访问 Token | 与服务器 `QUEUE_TOKEN` 一致 | `openssl rand -hex 24` 生成的那串 |

填完点「保存」，点「测试连接」应显示「✓ 连接成功，已索引 N 篇」。

## 使用

在 X 任意推文/文章页点「…」→ 菜单顶部点「保存到知识库」：

- 「已提交，云端归档中…」→ 成功，1-2 分钟后在服务器 `articles/` 和 GitHub 仓库出现
- 「这条已在知识库里」→ 重复提交，自动去重
- 红色提示 → 按提示排查（多为 token 不对或服务器没启动）

## 文件说明

| 文件 | 职责 |
|---|---|
| `src/content.js` | 注入菜单项（克隆 X 原生菜单项结构，样式/悬停跟随原生） |
| `src/background.js` | POST 链接到服务器 `/queue` |
| `src/popup.html/js` | 服务器地址与 token 设置、连接测试 |

服务器端部署见 `x-archive` 仓库 `server/DEPLOY.md`。
